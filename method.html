How we work.

Four steps, each documented, so that findings can be repeated and checked by someone else.

Good tradecraft is easy to repeat and easy to check.

  1. Scope

    Define the question, the requirement, and the limits before any collection starts.

  2. Collect

    Gather publicly available information, with every source documented as we go.

  3. Verify

    Test sources and claims. State how confident we are, and why.

  4. Report

    Deliver clear, defensible findings with the gaps and next steps called out.
